# BODY Q — GEIS Engine (English)

English implementation of the public GEIS research site.

- Live site: https://body-q-geis-engine.army78.chatgpt.site
- Korean version: https://body-q-geis-engine-kr.army78.chatgpt.site

## Run locally

```bash
npm ci
npm run dev
```

Use `npm run build` for a production build and `npm test` for the rendered-page checks.

The interface includes the five-domain calculator, imbalance penalty, transition-state simulation, Next Best Action guidance, research API architecture, wearable device bridge, and adaptive sampling controls.
